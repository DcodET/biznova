# BIZNOVA - منصة الأعمال والريادة
## Enterprise WordPress Block Theme (FSE) & Performance Architecture

تم تصميم وتطوير هذا القالب وفق أعلى معايير هندسة الواجهات وتجربة المستخدم (UI/UX) وبنية ووردبريس الحديثة **Full Site Editing (FSE)** لضمان سرعة تحميل فائقة وتوافق 100% مع الهوية البصرية الرسمية لمنصة **BIZNOVA**.

---

### 1. منظومة الألوان والهوية البصرية (Brand Identity)
- **الكحلي الداكن المؤسسي (Deep Navy Blue):** `#0C1E3C` — للعناوين الرئيسية، البطاقات الداكنة، والتباين العالي المستقر.
- **البرتقالي الحيوي (Vibrant Energy Orange):** `#F47521` — لأزرار التحفيز الأساسية (Primary CTAs)، حالات التركيز والتفاعل، وسهم النمو.
- **التدرج اللوني المتوهج (Gradient Accent):** من `#F47521` إلى `#FF9F43` — للشارات، الرسوم البيانية، ومؤشرات الأداء.
- **الأبيض والأوف وايت (Backgrounds):** `#FFFFFF` و `#F8FAFC` للتبادل بين الأقسام وإراحة عين القارئ.
- **الخطوط الطباعية (Typography):** خط **Readex Pro** للعناوين العريضة وخط **Cairo** للنصوص والمحتوى بوزن وحجم مريح للقراءة (16px base).

### 2. البنية البرمجية للقالب (Theme Architecture)

├── parts/

├── templates/
│   └── index.html          # تجميع القالب الكامل لصفحة البداية
├── patterns/

│   ├── features-why-us.php # بطاقات القيمة المضافة (لماذا BIZNOVA؟)

### 3. دليل التثبيت والتفعيل على ووردبريس
1. انسخ مجلد `wordpress-theme` إلى المسار:
   `wp-content/themes/biznova-theme` داخل موقع ووردبريس الخاص بك (أو قم بضغطه كملف zip ورفعه من لوحة التحكم).
2. توجه إلى لوحة تحكم ووردبريس: **المظهر (Appearance) > قوالب (Themes)**.
3. فعّل قالب **BIZNOVA - منصة الأعمال والريادة**.
4. **العدادات والإحصائيات الحية وبوابة الدفع الحقيقية:**
   - العدادات تبدأ تلقائياً من **الصفر (0)**، وترتفع تلقائياً لحظة بلحظة مع كل تفاعل حقيقي.
   - **بوابة الدفع الإلكتروني الحقيقية (Real Payment Gateway):**
     * الخطوة 1: إدخال بيانات العميل واختيار الخدمة (تم توحيد الأسعار على متوسط الميزانيات المعتمد 7,500 ج.م لكافة الخدمات الرئيسية، أو استشارة عامة مجانية 0 ج.م).
     * الخطوة 2: الانتقال لبوابة الدفع الحقيقية (Paymob بايموب الرسمية المعتمدة بالبنك المركزي، أو كاشير، أو رابط دفع سريع).
     * الخطوة 3: التحقق المشفر عبر الـ Webhook (HMAC-SHA512) وإصدار إيصال سداد رقمي موثق بكود معاملة فريد (`BZ-XXXXX-EGP` أو رقم معاملة البنك).
     * **قاعدة التوثيق المالي:** لا يتم تأكيد الحجز ولا زيادة عداد الاستشارات إلا **بعد إتمام السداد الحقيقي بنجاح**.
     * **عزل عداد المشاريع:** عداد "مشاريع تم إنجازها وتسليمها" معزول تماماً ولا يزداد إلا عند قيام الإدارة بتسليم المشروع فعلياً عبر لوحة التحكم.
   - **لوحة تحكم إعدادات بوابة الدفع في ووردبريس:**
     * مسار: **إحصائيات BIZNOVA > 💳 بوابة الدفع الحقيقية**.
     * إدخال مفاتيح Paymob (API Key, Integration IDs, Iframe ID, HMAC Secret) أو رابط دفع مباشر بنقرة واحدة.
     * رابط Webhook جاهز للنسخ إلى لوحة تحكم بايموب: `[site_url]/wp-json/biznova/v1/payment-callback`.
   - يتوفر في لوحة التحكم أيضاً: **إحصائيات BIZNOVA** و **🔒 الاستشارات المشفرة** لمشاهدة جميع العمليات مع بيانات التشفير وفك التشفير الآمن للمسؤولين.
5. **مستشارك الذكي (BIZNOVA Smart Assistant):**
   - يعمل تلقائياً لمساعدة الزوار في تشخيص وضع مشاريعهم وتحديد الخدمة الأنسب مع الأسعار المعتمدة بالجنيه المصري وربطها بالحجز والواتساب.
6. يمكنك تحرير كافة العناصر والأقسام مباشرة وبكل حرية عبر **محرر الموقع (Site Editor / Gutenberg)** بدون أي تعقيدات برمجية أو إضافات بناء ثقيلة.

### 4. استراتيجية سرعة الموقع (Core Web Vitals Blueprint - 95+)
- **Zero jQuery:** الموقع يعتمد على جافاسكربت نقية (Vanilla JS) بحجم لا يتجاوز 4KB، مما يقلل وقت معالجة المعالج (TBT < 50ms).
- **RTL-First Pure CSS:** تجنب التكرار واستخدام المتغيرات الأصلية (CSS Custom Properties) المدمجة مع `theme.json`.
- **Preconnect & Font Swap:** ربط خطوط Google Fonts عبر خاصية `preconnect` واستخدام `font-display: swap` للقضاء التام على ظاهرة وميض النص غير المنسق (FOUT).
- **No Layout Shift (CLS = 0):** تحديد أبعاد الصور والشعارات مسبقاً بنسب دقيقة.
- **Lazy Loading مدمج:** الاستفادة من ميزة التضمين الكسول الأصلية في ووردبريس لكافة الرسوم والصور.

### 5. منظومة الأمان والتشفير المتقدمة (Enterprise Security & Encryption)
تم تزويد القالب بنظام أمان وتشفير متكامل يعمل تلقائياً بمجرد التفعيل:
1. **تشفير البيانات الحساسة (AES-256-CBC Encryption):**
   - أرقام الهواتف، البريد الإلكتروني، وتفاصيل المشاريع تُشفر تلقائياً بمفاتيح OpenSSL المشفرة قبل التخزين في قاعدة البيانات.
   - عناوين الـ IP تخضع لتشفير أحادي الاتجاه (SHA-256 Salting) للامتثال الصارم لسياسات الخصوصية واتفاقيات عدم الإفصاح (NDA).
2. **الترويسات الأمنية الصارمة (HTTP Security Headers):**
   - تفعيل `X-Frame-Options: SAMEORIGIN` لمنع هجمات الـ Clickjacking.
   - تفعيل `X-Content-Type-Options: nosniff` لمنع حقن الملفات الخبيثة.
   - تفعيل `X-XSS-Protection` و `Strict-Transport-Security` لفرض اتصال SSL/HTTPS الآمن.
3. **حماية النواة وإخفاء بيانات النظام (Information Concealment):**
   - حجب وسم إصدار ووردبريس (`wp_generator`) وإزالة أرقام الإصدارات من الملفات البرمجية.
   - تعطيل بروتوكول `XML-RPC` بالكامل لمنع هجمات التخمين والـ Pingback DDoS.
   - حجب فحص أسماء المديرين من خلال واجهة REST API ومسار `?author=1`.
4. **مكافحة السبام وتحديد معدل الطلبات (Anti-Spam & Rate Limiting):**
   - حقل مصيدة خفي (Honeypot) يكشف ويحجب البوتات وبرامج التعبئة الآلية فوراً.
   - نظام تحديد معدل الطلبات (Rate Limiting) يسمح بحد أقصى 5 طلبات لكل عنوان IP خلال 10 دقائق لمنع الإغراق.
5. **خزنة الاستشارات المشفرة (Encrypted Leads Vault):**
   - تسجيل جميع الاستشارات في نوع مقال خاص وسري (`biznova_lead`) محمي من الوصول الخارجي ومتاح فقط لمدير الموقع من لوحة التحكم، مع فك تشفير البيانات عند العرض الإداري المأمون.
6. **ملفات الحماية للسيرفرات (`security/`):**
   - يتضمن مجلد `security/` قواعد حماية جاهزة لخوادم **Apache / LiteSpeed** (`htaccess-security.txt`)، وخوادم **Nginx** (`nginx-security.conf`)، وثوابت أمان `wp-config.php`.
